# Security policy

Release Evidence inspects repositories that may contain sensitive or hostile
content. Please report a suspected vulnerability privately instead of opening a
public issue.

Email `contact@drimini.com` with:

- a concise description of the issue and its impact;
- the affected command or component;
- reproduction steps or a minimal proof of concept; and
- any suggested mitigation, if known.

Do not include real credentials, private source code, personal data, or another
party's confidential information. Acknowledgement and remediation timelines
are not guaranteed while the project remains an experimental preview.

The project currently has no stable release or supported-version range. This
file will be updated before distributable binaries are described as supported.
